ARCHITECTURE
------------
RESULT → ResponsePolicy (imposed category) → optional LLM generateResponse
→ ResponseValidator → fallback → user

RESPONSE MODEL
--------------
ResponseDraft { text, tone, source, confidence, facts, warnings, category, usedLlm }
Facts supplied by JARVIS only.

LLM RESPONSE PROVIDER
---------------------
LLMProvider.understand() + LLMProvider.generateResponse()
Mock: deterministic French wording from facts
Ollama: RESPONSE_SYSTEM_PROMPT (FR, facts-only, no execution)
Unavailable → fallback, never fake success

POLICY
------
Categories imposed by runtime/DecisionEngine:
ACTION_SUCCESS/FAILURE/DENIED/CANCELLED/TIMEOUT/CONFIRMATION,
ANSWER, CLARIFICATION, REFUSAL, NO_ACTION, ERROR, DEFER

VALIDATION
----------
Rejects executable shell blocks, tool calls, permission/confirmation claims,
invented action claims without ACTION_RESULT facts.
Allows discussing that shell commands cannot be run.

FALLBACK
--------
ResponseDraftFormatter.fallback() always available; used when LLM missing
or validation rejects LLM wording.

CONVERSATION
------------
Assistant text still stored in ConversationStore via finish();
not auto-written to MemoryStore.

MEMORY
------
Budgeted hints (max 5 / 800 chars) as CONTEXT only — never authority.
Explicit user request still wins (Phase 17/18).

ACTION RESULTS
--------------
Runtime naturalize() after execute success/failure and confirmation.
Narrates e.g. "Safari est ouvert." from facts.

CONTEXT RESULTS
---------------
handleContextIntent naturalizes ANSWER with contextResult.available flag;
unavailable → no invented screen/app state.

SECURITY
--------
src/response forbids ActionExecutor/PermissionManager/ActionConfirmation/
FileService/ApplicationService/BehaviorBrain/shell/native automation.
Security answers keep disclaimer; no "piraté" without evidence.

PERFORMANCE
-----------
Simulation (deterministic generator, no LLM): avg ~0.003ms over 5000.
No fictional user SLA.
