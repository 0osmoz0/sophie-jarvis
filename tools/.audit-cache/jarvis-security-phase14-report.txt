2. SECURITY SIGNAL MODEL
------------------------
SecuritySignal { id, category, kind, severity, confidence, timestamp, source, evidence, reason }

Categories: USER_PRESENCE | APPLICATION | SCREEN | FILE | SYSTEM | SESSION | ENVIRONMENT
Severities: INFO | LOW | MEDIUM | HIGH | CRITICAL
CRITICAL = highest alert severity only — never auto-action.

Vocabulary: ANOMALY / SUSPICIOUS / UNUSUAL / UNKNOWN / HIGH_RISK_SIGNAL
Always with confidence + evidence + reason.
Never claims virus / malware / hacker / intrusion without dedicated proof.

3. BASELINE
-----------
SecurityBaseline — bounded in-memory only (history ≤ 8)
Non-persistent by default
Stores metadata keys only (apps, idle, file fingerprints provided, memory/uptime)
Never stores: screenshots, passwords, file contents, keystrokes, clipboard, camera, mic

4. THREAT ASSESSMENT ENGINE
---------------------------
ThreatAssessmentEngine — simple explainable scoring + light temporal correlation (~15 min window)
SecuritySequence kinds list for correlated idle → app → frontmost → file patterns
Conservative: prefers unknown over false accusation
Benign app hints (Spotify, Chrome, Safari, Cursor, …) capped ≤ LOW when isolated

5. CORRELATION
--------------
On-demand assess only — no permanent scheduler, no aggressive setInterval loop in security layer
Sequence example: user idle + new/unknown app + frontmost change + file metadata change

15. LIMITATIONS (PRECISE)
-------------------------
- Not an antivirus or EDR
- Cannot confirm malware, virus, hacker, or intrusion
- Cannot prove physical presence or identity
- IDLE ≠ ABSENT
- No network/firewall/quarantine/blocking
- No automatic file/app/process mutation from alerts
- No camera, microphone, SMS, calls, browser automation, input injection
- Baseline is session memory only — no durable threat memory
- Confidence is capped; unknown preferred over accusation
- File anomalies require explicitly supplied metadata (policy paths upstream)
- Screen anomalies are window metadata only — no content analysis

WHAT JARVIS CANNOT CLAIM
------------------------
virus detection
malware detection
hacker detection
physical presence
identity recognition
intrusion confirmation

(unless a future dedicated capability provides real evidence)
