4. STATE MACHINE
----------------
ACTIVE --(idle >= idleThreshold)--> JUST_BECAME_IDLE --> IDLE
IDLE   --(idle <= returnThreshold)--> JUST_RETURNED --> ACTIVE
Statuses: ACTIVE | IDLE | JUST_BECAME_IDLE | JUST_RETURNED | UNKNOWN

5. THRESHOLDS
-------------
idleThresholdSeconds = 30 (default behavioural only — not a security trigger)
returnThresholdSeconds = 2 (hysteresis)
Both configurable via UserActivityServiceConfig.

6. PRESENCE MODEL
-----------------
PRESENT | IDLE | UNKNOWN
IDLE = no aggregate activity detected — NOT physical absence.
No camera / microphone / physical presence claim.
