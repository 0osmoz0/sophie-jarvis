2. ARCHITECTURE
---------------
Pipeline (mandatory):

  User / UI / Voice
         ↓
      Intent
         ↓
    JarvisCore
         ↓
  PermissionManager
         ↓
       Tool
         ↓
      Result
         ↓
      Sophie   (via SophieBridge — stub only in Phase 1)

Components:
- RiskLevel: LOW | MEDIUM | HIGH | CRITICAL
- Tool + ToolRegistry (registry does not execute)
- PermissionManager (sole gate before execute)
- TaskManager (lifecycle only, no system commands)
- EventBus (typed task_* events)
- Context (read-only demo snapshot, no surveillance)
- JarvisCore (structured Intent orchestrator)
- AIProvider + MockAIProvider (propose Intent only; no LLM network)
- SophieBridge / NullSophieBridge (decoupled stub)
- SecurityEvent (scaffolding)
- Only real tool: system.info (LOW, Node os module, no shell)
