------------------
1. Données réellement disponibles?
   Displays (count, primary, size, scale, bounds), apps active+running,
   window metadata (title/bounds when permitted), idleSeconds,
   session.locked when present, permission capability reports.
2. Fiables?
   NSScreen displays; IOKit idle duration; NSWorkspace running/frontmost
   (bridge); Node system; session.locked if key present.
3. UNKNOWN?
   session.userPresent (often null); activity when backend unavailable;
   microphone permission state; anything without source.
4. Permissions?
   Accessibility (frontmost/windows cases); Screen Recording (windows/
   capture); Microphone = Voice only, not env observation.
5. Écrans?
   displayCount, primary, width/height/scaleFactor, bounds, globalBounds.
6. Applications?
   active, runningCount, recentApplications (≠ active).
7. Fenêtres?
   active window id/title/app/bounds flags; heuristique focus CG.
8. Activité?
   idleSeconds + activityLevel ACTIVE/RECENTLY_ACTIVE/IDLE/UNKNOWN;
   IDLE ≠ ABSENT.
9. Session?
   locked / userPresent; UNKNOWN if both null (never coerced to false).
10. Curseur?
    NON — available=UNAVAILABLE (pas d’API fiable).
11. Audio?
    NON — UNAVAILABLE / EXTERNAL_INTEGRATION; open ≠ playing.
12. Fraîcheur max?
    FRESH ≤ ~2s; STALE ≥ ~15s; ageMs exposé; snapshot on-demand.
13. Duplications restantes?
    SecurityMonitor peut encore double-snapshot; Phase2 stubs vs native;
    frontmost NSWorkspace vs CG active window.
14. Sophie peut recevoir?

    d’événements BehaviorBrain / animations.

    via EnvironmentHints (clarify si multi).

    fuite titres fenêtres (metadata) — pas de pixels/OCR.
17. Problèmes restants?
    Pas de curseur/now-playing; fenêtre active heuristique;
    userPresent null; pas de bridge AX dédié.
