No generic/shell action. Typed payloads only.

3. RISK MODEL
-------------
LOW / MEDIUM / HIGH / CRITICAL
CRITICAL → always DENIED
Unknown action → DENIED
FILE_DELETE → HIGH; other Phase 8 mutations → MEDIUM

4. CONFIRMATION MODEL
---------------------
ActionConfirmation binds taskId + actionType + payloadHash + expiresAt
Single-use; cross-task and payload mismatch rejected
Readable ActionConfirmationRequest (never "execute this command?")

5. EXECUTOR
-----------
ActionExecutor delegates only to FileService / ApplicationService
No direct node:fs, no native macOS APIs, no shell

6. DRY-RUN
----------
plan/execute with dryRun:true describes effects without mutation
Does not mark plan COMPLETED

7. IDEMPOTENCE
--------------
COMPLETED taskId cannot execute again → ALREADY_COMPLETED

8. CANCELLATION
---------------
cancel(taskId) before EXECUTING only
After EXECUTING → CANCEL_UNAVAILABLE

9. ROLLBACK
-----------
Conceptual ActionRollback:
FILE_COPY → optional tracked destination delete when AVAILABLE
FILE_MOVE / FILE_CREATE / APP_OPEN → UNAVAILABLE
FILE_DELETE / APP_CLOSE → UNSUPPORTED
