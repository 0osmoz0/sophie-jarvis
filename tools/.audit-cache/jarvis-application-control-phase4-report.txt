4. APPLICATION POLICY
---------------------
- Risk assignment per action
- Denylist for critical system apps
- Blocked path prefixes for open/close
- Power verbs (shutdown/restart/logout/sleep) denied

5. DENYLIST
-----------
Finder, Dock, WindowServer, loginwindow, launchd, SystemUIServer
(+ matching bundle IDs)

/System/*, /Library/*, /private/*, /usr/*, /bin/*, /sbin/*

6. RESOLVER
-----------
Resolves name / bundleId / path / id from explicit registry only.
Rejects command-like input (&&, ;, |, $, etc.) as INVALID_INPUT.
Never treats identity as a shell command.

(no find/mdfind/ls/ps).
