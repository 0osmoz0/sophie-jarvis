STORAGE
-------

PERSISTENCE
-----------

Custom path: JARVIS_MEMORY_PATH
No SQLite, no network

VALIDATION
----------
MemoryValidator: schema, bounds, secret patterns, command patterns, injection
Reasonable (not naive keyword ban)

POLICY
------
STORE / REJECT / TEMPORARY
Secrets & commands → REJECT
Transient / low confidence / hedging → TEMPORARY + expiry

DEDUPLICATION
-------------
Normalized similarity + preference topic + shared entities → merge

CONFLICTS
---------
Newer explicit preference/decision on same topic → CONFLICT_RESOLVED (supersede)

RETENTION
---------
temporary / low confidence: expiresAt
expireDue on list/recall/remember
Audited EXPIRE operations

RETRIEVAL
---------
recall(query, budget { maxMemories:5, maxCharacters:800 })
ContextSnapshot.memory = relevant subset only (system.context)
